# img2ascii converter
Available at: [https://timurius.github.io/ascii_converter/](https://timurius.github.io/ascii_converter/)

---
### Status
In development
### Features
- Drag-n-drop input of images
- Independent processing modes as separate methods
- ASCII output scaling
- Conversion of images to ASCII art by calculating mean RGB value
- Colour output
